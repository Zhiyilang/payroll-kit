# 工资条/考勤自动核算器（payroll-kit）

> 零依赖（纯标准库，不装 pandas/openpyxl）、中文表头、按月度个税累进表的**考勤→工资条**一键核算工具。
> 输入一张考勤 CSV，输出带「应发 / 扣款 / 社保 / 个税 / 实发」完整工资表 CSV。HR、小老板、 freelancer 月度算薪通用。

**作者**：支一郎 (Zhiyilang) · **许可证**：MIT · **赞助**：https://afdian.com/a/zhiyilang

## 为什么值得上架 / 接单
- **中国职场刚需**：每个月都有人问"工资怎么算""个税怎么扣"，Excel 公式易错、规则一改就乱。
- **零依赖**：很多办公/财务电脑没装 pandas；本工具纯标准库，双击 `python main.py` 就能跑，不会"本地能跑线上崩"。
- **可卖点清晰**：HR 算薪、小团队发工资、 freelancer 给客户出工资条——都是付费意愿强的场景。

## 用法

```bash
python main.py          # 用内置「考勤示例.csv」演示，生成「工资表.csv」
python -m unittest discover -s tests   # 跑单元测试（标准库，无需 pytest）
```

自定义：把你的考勤表按 `考勤示例.csv` 的列（姓名,部门,应出勤,实际出勤,迟到次数,请假天数,基本工资）填好，改 `main.py` 里的 `rule` 即可：

```python
rule = {
    "late_fee": 50.0,      # 每次迟到扣款
    "leave_fee": 100.0,    # 每天请假扣款
    "social_rate": 0.105,  # 社保个人比例（养老8%+医疗2%+失业0.5%）
    "threshold": 5000.0,   # 个税起征点
}
```

## 核算逻辑（透明可审计）
- 缺勤扣款 = (应出勤 − 实际出勤) × 日薪，日薪 = 基本工资 ÷ 应出勤
- 扣款合计 = 缺勤扣款 + 迟到扣款 + 请假扣款
- 应发 = 基本工资 − 扣款合计
- 社保个人 = 应发 × 社保比例
- 应纳税所得额 = 应发 − 社保 − 起征点（≤0 免税）
- 个税 = 按 2019 起月度累进税率表（速算扣除法）
- 实发 = 应发 − 社保 − 个税

> ⚠️ 个税为**参考计算**，非税务申报依据；社保比例各地不一，请按本地政策调整 `social_rate`。
